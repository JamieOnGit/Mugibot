                  Browser extension

                  Checking for the extension…

                  1. Install

                  Add to Chrome

                  From the Chrome Web Store. It updates itself, so you never have to replace it. Works in Chrome, Edge and Brave. Then come back to this page and reload it.

                  Or download it instead (it won't update itself)
                  1. Download the extension and unzip it.
                  2. Open chrome://extensions (Edge: edge://extensions) and turn on Developer mode.
                  3. Click Load unpacked and choose the unzipped …-extension folder.
                  4. Come back to this page and reload it.

                  Updating the extension

                  The copy from the Chrome Web Store updates itself. If yours was downloaded from this page, move to it once:

                  1. Add to Chrome from the Chrome Web Store.
                  2. Come back here, reload the page and press Connect this browser below.
                  3. Save your card in it: click its icon → Add your card.
                  4. Remove the old copy: its icon shows OLD. Click it → Remove this copy (or at chrome://extensions, press Remove on the Mugibot that isn't from the Chrome Web Store).

                  From then on, new versions install themselves.

                  When there's a new version, the extension's icon in Chrome's toolbar shows NEW and its popup has an Update button that brings you here. Updating like this keeps your saved card.

                  1. Download the latest version and unzip it.
                  2. Open the new mugibot-extension folder, select everything in it (⌘+A on a Mac, Ctrl+A on Windows) and copy it into the folder your extension was loaded from, replacing the old files. Not sure which folder? Open chrome://extensions → Mugibot → Details: it's under Source.
                  3. Click the Mugibot icon in Chrome's toolbar → Reload (or the ↻ on Mugibot at chrome://extensions). If it asks, press Connect this browser below.

                  Or start fresh: at chrome://extensions press Remove on Mugibot, then Load unpacked and choose the new folder, press Connect this browser below, and save your card again.

                  4. Sign in at the stores

                  Signed in at a store, ⚡ Buy's checkout is faster: the store fills in your saved address (and often your card) itself. The extension notices whether you're signed in whenever you open a store, and checks the stores that show it in their pages every 10 minutes. It only looks: nothing is clicked or typed.

                    In-browser checks

                    Some stores (Kmart, for one) refuse stock checks from servers. For those, this browser re-checks your own SKUs about every 60 seconds while it's open — the same as refreshing the page yourself. If a store shows a bot check, it backs off. It never tries to get past one.
